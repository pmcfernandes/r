# MicroMVC (Vite)

This is a tiny Vite wrapper for the existing MicroMVC sources in this folder.

Basic commands (PowerShell):

```powershell
# install dev deps
npm install

# start dev server (open http://localhost:5173)
npm run dev

# build production bundle into dist/
npm run build

# preview the production build
npm run preview
```

The entry point is `index.js` which bootstraps the app.
